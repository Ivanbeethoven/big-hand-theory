# 安全与威胁模型

移动办公把工作入口扩展到家用网络、云主机、移动设备和 Agent。每多一个可达入口，都要明确谁能连接、能看到什么、能执行哪些操作。

## 基线

- 远程服务放在私有网络、VPN 或有身份校验的访问网关后面。不要把 RDP/VNC/管理面板直接映射到公网。
- 使用 MFA、SSH 密钥和设备级授权；关闭默认口令和不需要的账户。
- 个人日常账户与管理员账户分开；远程会话按任务授予最小权限。
- 限制远程剪贴板、磁盘映射、下载目录和凭据转发。
- 记录设备、登录时间和管理员操作；离职、设备丢失或更换时撤销密钥和会话。
- 及时更新客户端、服务端、操作系统和自托管依赖，并备份配置。

## Agent 专项

- Agent 使用独立容器、虚拟机或工作区，不直接使用主力电脑的管理员会话。
- 不把生产密钥、密码库、私人文件或主浏览器登录态提供给实验任务。
- 默认阻止任意外网访问；需要网络时按任务设置域名或 API 范围。
- 对付款、删除、发信、发布、账户安全设置等不可逆动作设置人工确认。
- 检查 Agent 生成的命令、代码差异和浏览器操作结果，再进入正式环境。
- 为任务设置时长、资源和费用上限，并能从控制端快速停止会话。

## 失联时

保留本地可用的任务说明和最近工作副本；重要文件有版本化备份；服务器使用带外控制台或云厂商恢复入口。远程能力不应成为唯一副本或唯一登录路径。
